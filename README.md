## 画像について

現状、写真を1枚も使っていません（お預かりしていないため）。
タイポグラフィだけで成立する設計にしてあるので、写真ゼロでも公開できます。

ただし **OGP画像（SNSでシェアされたときのサムネイル）だけは用意を強く推奨** します。
`img/ogp.jpg`（1200×630px）を置いて、各ページの `<head>` に以下を追加してください。

```html
<meta property="og:image" content="https://wolf-tenmonkan.com/img/ogp.jpg">
```

店内写真が用意できたら、トップの狼マークの位置と、アクセスページのビル外観に入れると効果的です。
特に**ビルの外観写真**は、初来店の方が迷わないための実用的な効果があります。

## MEO（マップ検索）対応

MEOは「サイト側の下地」と「Googleビジネスプロフィール側の運用」の両輪です。
**サイト側の下地は実装済み。順位を動かす主役はプロフィール側の運用**なので、
下の「オーナーがやること」を必ず実施してください。

### ✅ サイト側で実装済み（このリポジトリ）

- **LocalBusiness 構造化データ**（`BarOrPub`＋`CafeOrCoffeeShop`）— 店名・住所・
  緯度経度・電話・営業時間・料金帯・支払い方法・年齢制限・予約先・エリア・画像・ロゴ
- **Googleマップ埋め込み**（トップ／アクセス）と、正規の **CID リンク**（`sameAs`・`hasMap`）
- **経路案内リンク**（トップ／アクセスの「Googleマップで経路案内」ボタン）
- **クチコミ導線**（アクセスの「マップで見る・クチコミ」ボタン）
- NAP をサイト全ページで統一、`sitemap.xml` / `robots.txt` 完備

### 🔲 オーナーがやること（MEOの主役）

1. **Googleビジネスプロフィールを開き、「ウェブサイト」欄に `https://wolf-tenmonkan.com` を登録**
2. **NAP（店名・住所・電話）をプロフィールとサイトで完全一致させる**
   - サイトの表記：`ボードゲームカフェ＆bar WOLF` ／
     `〒892-0842 鹿児島県鹿児島市東千石町4-28 リファレンス東千石町ビル 3F` ／ `099-221-1578`
   - **マップ上の登録名が全角の「ボードゲームカフェ＆ｂａｒＷＯＬＦ」なので、半角に統一**推奨
3. **カテゴリを設定**：主「ボードゲームカフェ」＋副「バー」など
4. **営業時間を 1:30–8:30／年中無休で一致**させる
5. **写真を継続的に投稿**（店内・卓・ドリンク）— マップ経由の来店にこれが一番効きます
6. **クチコミを集め、返信する** — 件数と新しさが順位に直結します
7. **Google Search Console に `wolf-tenmonkan.com` を登録** → `sitemap.xml`（`https://wolf-tenmonkan.com/sitemap.xml`）を送信
   - 所有権確認は、エックスサーバーのDNSに **TXTレコード**を1件足す方法が簡単です（GitHub Pagesでも可）

> クチコミ依頼リンクを名刺やレシートに載せたい場合は、Place ID があると
> 直リンク（`https://search.google.com/local/writereview?placeid=…`）が作れます。
> 必要になったら取得してお渡しします。

### 確認しておいたほうがいい件

同じ住所・同じ電話番号で [鹿児島ポーカーハウスWOLF](https://www.pokerhouse-wolf.com/)（東千石町4-28 3F / 099-221-1578）が別サイト・別Googleプロフィールで存在します。

**同一住所・同一電話番号で複数のビジネス登録があると、Googleが実体を1つと判断して片方の表示を抑制することがあります。** 対応は2択です。

- **同一運営として整理する** — どちらかを主、もう一方を「同じ場所で営業する別業態」として扱い、サイト間を相互リンクする
- **完全に分離する** — 電話番号を分ける（内線・別番号）と、Googleは別実体として認識しやすくなります

どちらを取るか決めたら、サイト側の記述も合わせて調整します。

### 深夜営業に合わせた記述の調整

開店が深夜1:30と判明したため、アクセス記述を実態に合わせています。
**その時間には市電もバスも動いていない**ため、「最寄り電停」を主導線にすると役に立ちません。
[access.html](access.html) では徒歩・タクシーを主、市電を「お帰りの始発用」として記載しています。
また飲み放題付きのため、車での来店は積極的に案内していません。

## デザインの仕様

- **色** — 深炭 `oklch(15% 0.012 60)` にランタン色の琥珀 `oklch(76% 0.155 68)`。アクセントは画面の3%以下に抑制
- **書体** — 見出し Zen Old Mincho ／ 本文 Zen Kaku Gothic New ／ 数値 JetBrains Mono（Google Fonts）
- **構造** — Split Studio（左に言葉、右に事実、下るごとに左右反転）
- 色・書体・余白はすべて `css/tokens.css` の変数。ここだけ書き換えれば全ページに反映されます
- ダークテーマですが本文コントラストは 4.5:1 以上を確保しています
- `prefers-reduced-motion` 対応済み。キーボード操作・スクリーンリーダー対応済み
